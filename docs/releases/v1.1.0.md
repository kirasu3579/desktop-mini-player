首个公开版本（1.1.0）。

## 功能

- **悬浮播放条**：无边框、可拖动、可置顶，不占任务栏；按住任意空白处即可拖动，指针位移 ≥4px 才算拖动，否则当点击。
- **逐字卡拉 OK**：宿主给出逐字时间轴时，当前句按播放进度逐字点亮（已唱实色 / 未唱 42% / 正在唱的那个字按比例填充）。宿主只给词组级 cell 时按权重拆成单字（汉字 1 份、标点与空格 0.25 份），保留标点与长音的停顿感；含拉丁字母的 cell 不拆。
- **超宽歌词滚动**：行太长时跟着演唱边界滚动到句末，行尾那截一定露出来，不截断。
- **封面单击唤起主窗口**：最小化→还原、被丢到屏幕外→拉回屏内、然后提到前台。只认可见且有标题的宿主主窗，关掉界面后点击安静无事。
- **进度条**：悬停变粗并显示 `当前/总长` 气泡，左键拖动跳转。
- **右键菜单**：锁定位置 / 暂停时隐藏 / 深色主题 / 从任务栏抽出 / 重置位置 / 隐藏迷你条。
- **设置面板**：「启用迷你播放器」开关改完立刻生效；另有「显示 / 隐藏迷你条」「重置窗口位置」「显示当前设置」按钮。

## 修复

- **卡拉 OK 句尾最后一个字只亮一部分就换行**：边界推进用「逐格 `FontMetrics.stringWidth` 之和」当整行宽度，而绘制判断用整串宽度，两者在宿主 cell 带首尾空格或标点单独成格时不等，边界只走到整行的 95%~97% 就被换行截断。现在按 `textW / Σwidth` 整体归一，只缩放总长、不改格间节奏。

## 注意：插件 ID 已变更

本插件此前使用过带第三方产品名的旧 ID，为避免侵权已改为 `com.miniplayer.desktop-mini-player`。

**从旧版本升级时**，装新版前请先删掉 `%APPDATA%\Salt Player for Windows\workshop\plugins\` 下所有残留的 `plugin-com.miniplayer.*` 旧目录，否则 PF4J 会把新旧两个 ID 当成两个插件同时加载，桌面上出现两条播放条。旧配置（位置、主题、开关）不会自动迁移。

## 安装

1. 关闭 Salt Player。
2. 下载本页下方的 `.spmod`，解压到 `%APPDATA%\Salt Player for Windows\workshop\plugins\com.miniplayer.desktop-mini-player-1.1.0\`。
3. 启动 Salt Player，迷你条会自动弹出。

首次运行会申请 `library-read` 权限，**只用于读取封面图**；不授权也能正常播放控制，只是封面位置显示占位音符。

## 环境

- 宿主：Salt Player for Windows（创意工坊 API `0.1.0-dev22`）
- 运行时：Java 25 必需（插件用 Java 25 编译）
- 无第三方运行时依赖，只带 kotlin-stdlib / annotations
